# سَنَد · Sanad Platform

منصة موحّدة لإدارة الجمعيات الخيرية في المملكة العربية السعودية.
تجمع: **الموقع العام + متجر التبرعات + النظام الإداري الداخلي** في تطبيق واحد.

> **Code name:** Sanad (سَنَد) — اسم تجريبي محايد، يُستبدل عند الإطلاق الرسمي.

---

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح: <http://localhost:3000>

## الصفحات الأساسية

| المسار | الوصف |
|--------|------|
| `/` | الصفحة الرئيسية للموقع العام |
| `/تبرع` | نموذج التبرع (Apple Pay + مدى) — تجريبي |
| `/حملات` | قائمة الحملات النشطة |
| `/كفالات` | تصفّح الكفالات |
| `/admin` | لوحة النظام الإداري |
| `/admin/مستفيدون` | قائمة المستفيدين |
| `/admin/مستفيدون/[id]` | ملف المستفيد الموحّد |

## التقنيات

- **Next.js 16** · App Router · Turbopack
- **React 19**
- **TypeScript 5**
- **Tailwind CSS v4**
- **Supabase** (Postgres + Auth + Storage) — جاهز للتوصيل
- **Lucide React** للأيقونات
- **IBM Plex Sans Arabic** كخط أساسي

## هيكل المشروع

```
src/
├── app/
│   ├── (public)/           ← الموقع + المتجر
│   │   ├── layout.tsx
│   │   ├── page.tsx        ← الصفحة الرئيسية
│   │   └── تبرع/page.tsx   ← نموذج التبرع
│   ├── admin/              ← النظام الداخلي
│   │   ├── layout.tsx
│   │   ├── page.tsx        ← لوحة اليوم
│   │   └── مستفيدون/
│   │       ├── page.tsx        ← القائمة
│   │       └── [id]/page.tsx   ← الملف الموحّد
│   ├── layout.tsx          ← Root + RTL + خط عربي
│   └── globals.css         ← Design System
├── components/
│   ├── public/             ← مكوّنات الموقع العام
│   ├── admin/              ← مكوّنات النظام الداخلي
│   └── ui/                 ← مشتركة
└── lib/
    ├── utils.ts
    ├── supabase.ts
    └── sample-data.ts      ← بيانات تجريبية
```

## النشر على Vercel

1. ادفع الكود إلى GitHub
2. اذهب إلى <https://vercel.com/new>
3. اربط الـ repo
4. اضغط Deploy
5. خلال 60 ثانية يطلع رابط: `sanad-platform.vercel.app`

## متغيّرات البيئة

انسخ `.env.example` إلى `.env.local` وعبّئ القيم.

في المرحلة الحالية يعمل المشروع **بدون Supabase** ببيانات تجريبية،
للتجربة فقط. عند توصيل Supabase تصير البيانات حقيقية.

## ملاحظات

- ⚠️ **نموذج تجريبي** — لا تتم معاملات مالية حقيقية
- 🌐 عربي 100% (RTL أصيل، خط عربي مُحسَّن)
- 🌙 دعم الوضع الداكن
- ♿ يحترم `prefers-reduced-motion`
- 📱 mobile-first
